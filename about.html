About JettUnified

Why it exists and how it is built.

Running a survival server usually means stacking ten or more plugins. One for homes, one for kits, one for teams, one for bans, one for the TAB list. Each one has its own config style, its own data files and its own update schedule. When one breaks, you have to find out which.

JettUnified puts all of that into one plugin. Every feature is a module. Modules share the same storage, the same message format and the same commands for reloading and backups. You keep the ones you need and switch off the rest.

How it's built

Modules, not one big plugin. Each module loads, reloads and unloads on its own. Turning one off with /ju reload removes its commands and listeners without a restart.

Safe storage. Economy and teams use SQLite. Everything else is saved with safe file writes, so a crash during a save can't corrupt your data.

GUIs where they help. Kits, recipes, SMPCore rules and team settings can be changed in-game. Config files are still there and fully commented if you prefer them.
