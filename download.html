Install in four steps

  1. Stop your server.
  2. Put the jar in plugins/. Remove any older JettUnified jar.
  3. Start the server. Configs are created in plugins/JettUnified/.
  4. Choose your modules in modules.yml and run /ju reload.

New here? Read the installation guide and see what's in this release.

Before you update

Back up your database with /ju storage backup. Your config files are kept when you replace the jar.
