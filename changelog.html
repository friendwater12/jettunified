Changelog

Every release of JettUnified and what changed.

1.0
November 2026
Latest

First release

  • 21 modules: Spawn, Lobby, Homes, Warps, Back, TPA, RTP, Kits, Teams, Economy, Ender Chest, InvSee, EcSee, Custom Recipes, Broadcast, TAB, Rank Display, SMPCore, Moderation, Admin Tools, Utilities.
  • Module Manager GUI and live enable/disable with /ju reload.
  • Two builds: Paper 1.21.x (Java 21) and Paper 26.3 (Java 25).
  • Over 130 commands and 140 permissions, all configurable.

Storage

  • SQLite database for economy and teams, created on first start.
  • YAML data is now saved with safe writes (temp file, then swap).
  • /ju storage with status, backup, migrate and integrity.

Fixes

  • Full code audit: all critical, must-fix and polish issues closed.
  • Power tools only run commands from an allowlist (powertool.allowed-commands).
  • /sudo no longer gives the target OP.
  • Jailed players can now respawn after death.
  • /tempban, /mute and /jail durations support weeks (w).
  • /rtp finds safe spots in the Nether.
  • Team MOTD and titles can no longer inject formatting tags.
  • Team invites now expire, and disbanding a team needs confirmation.

Known

  • Vanish is paused in this release.
