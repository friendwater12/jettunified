Features

Every module in JettUnified 1.0, with what it does and the commands it adds. All modules can be turned off in modules.yml.

Spawn

A server spawn point with a teleport delay and cooldown.

modules.spawn
  • Set the spawn point in-game
  • Teleport delay with cancel-on-move
  • Per-use cooldown
/spawn/setspawn

Lobby

A separate lobby location with its own delay, cooldown and sounds.

modules.lobby
  • Set the lobby point in-game
  • Configurable start and success sounds
  • Optional delay and cooldown
/lobby/setlobby

Homes

Personal homes with a limit per player.

  • Home limit per player (default 3)
  • Unlimited homes by permission
  • Optional overwrite of existing homes
  • Teleport delay and cooldown

Server warps, with optional player-created warps.

  • Optional player warps with a per-player limit
  • Unlimited player warps by permission
  • Teleport delay and cooldown
/warp/warps/setwarp/delwarp

Back

Return to your last location after a teleport or death.

modules.back
  • Records location before death
  • Records location before teleport
  • Delay and cooldown
  • Can be blocked after PvP deaths (SMPCore Combat)
/back
Teleportation

TPA

Teleport requests between players.

modules.tpa
  • Requests expire after 60 seconds (configurable)
  • Request to you or to them
  • Players can toggle requests off
  • Delay, cancel-on-move and cooldown
/tpa/tpahere/tpaccept/tpdeny/tpaall/tptoggle/tp
Teleportation

RTP

Random teleport to a safe spot in the world.

modules.rtp
  • Min and max radius (500 – 5000 blocks by default)
  • Avoids water, lava and leaves
  • Option to only use already generated chunks
  • Async chunk loading
  • Sound and particle effects
  • Cooldown with bypass permission
/rtp

modules.kits

Teams

Player teams with roles, chat, allies, homes, warps and a shared ender chest.

modules.teams
  • Owner, promote and demote roles
  • Public or invite-only teams
  • Invites expire after 60 seconds
  • Disband needs confirmation
  • Team chat and ally chat
  • Team home and up to 5 team warps
  • Shared team ender chest (27 or 54 slots)
  • Team color, title and MOTD
  • Friendly-fire toggle
  • Team prefix in TAB, chat and nametags
  • Team settings GUI

Server

SMPCore

Gameplay rules for survival servers, all managed from one GUI.

modules.smpcore.enabled

Potion Limiter

Block any potion in normal, long and strong forms. It also blocks splash, lingering and tipped arrow versions. Click a potion in the menu to toggle it.

Enchant Limiter

Block an enchantment or set its max level, including mace enchantments. Bypass items work by item type. Certified items bypass all limits with a hidden ID on that one copy.

Combat

Combat timer (20 s by default) with optional combat-log kill. You can block commands, teleports, ender pearls, riptide, elytra, totems in combat and /back after a PvP death.

World Rules

Over 40 switches: portals, explosions, mob spawning, villager trading, fire spread, water and lava flow, raids, weather, natural regen, fall damage, PvP and workstation blocks.

Quality of Life

Auto-smelt, tree capitator, vein miner, double doors, silk-touch spawners, auto pickup, death chests (15 min expiry) and crop replant.

Block Item

Remove listed item types from the server with a warning. Certified items are still allowed.

Cooldown Control

Add an extra use cooldown to any item type, up to 300 seconds by default.

Item Limits

Set the most of an item type a player can carry. Main inventory, hotbar, offhand and armor all count.

/smpcore/certified/blockhanditem/itemlimit

Core

Plugin core

Shared systems used by every module.

  • Module Manager GUI (/ju modules)
  • Enable or disable modules with /ju reload
  • SQLite database for economy and teams
  • YAML fallback if SQLite is unavailable
  • Safe file writes for all YAML data
  • Storage status, backup, migrate and integrity check
  • MiniMessage formatting in messages
  • No external database needed
  • Every message editable per module
