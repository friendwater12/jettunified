Why JettUnified

Fewer plugins. Less to keep in sync.

Most survival servers run separate plugins for homes, warps, kits, teams, moderation, TAB and economy. Each has its own data files and update cycle. JettUnified puts them under one roof.

01

Modular by design

Every module has its own folder with config.yml and messages.yml. Disable what you don't need from modules.yml or the in-game Module Manager.

02

Safe storage

Economy and team data live in an SQLite database that is created on first start. Other data is saved with safe file writes, so a crash mid-save can't corrupt it. /ju storage checks and backs it up.

03

Managed in-game

Kits, custom recipes, SMPCore rules, team settings and modules all have GUIs. Most changes save instantly, without editing files.

SMPCore

Set the rules of your SMP from one menu.

Run /smpcore to open the SMPCore Manager. Block potions, cap enchant levels, set combat rules and switch off world mechanics, all by clicking.

  • Enchant Limiter with certified items that bypass limits
  • World Rules with 40+ switches for portals, explosions, spawning and more
  • Combat timer, combat-log kill, pearl and elytra blocks
  • Item Limits, Block Item and Cooldown Control
  • Quality of Life: vein miner, tree capitator, death chests
